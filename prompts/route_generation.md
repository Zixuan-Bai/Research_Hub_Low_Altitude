# Prompt: Route Generation

You are generating route cards from a topic brief and evidence map.

Use `route_cards/templates/route_card.md`.

## Task

Generate candidate route cards.

## Each Route Must Include

- core research question;
- why the problem matters;
- literature basis;
- practical context basis;
- gap;
- proposed angle;
- minimal model;
- possible method;
- expected evidence;
- baselines;
- feasibility;
- risks;
- decision recommendation.

## Rules

- Do not create a route without supporting literature, unless it is explicitly marked as speculative.
- Do not create a route based only on academic trend. Check practical system, standard, policy, or industry evidence first.
- Mark deployment uncertainty explicitly.
- Do not recommend creating a Level 1 implementation repository unless feasibility is at least medium and human review is still required.
- Do not modify baseline assumptions unfairly.
- Do not create final paper claims.
