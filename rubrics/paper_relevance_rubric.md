# Paper Relevance Rubric

Score each candidate paper from 0 to 5.

## 1. Topic Fit

5: Directly studies the target topic.

3: Related but requires interpretation.

1: Only loosely connected.

## 2. Technical Substance

5: Provides model, algorithm, proof, simulation, measurement, or standard detail.

3: Provides partial technical detail.

1: Mostly descriptive or regulatory.

## 3. Evidence Value

5: Provides reusable evidence for assumptions, baselines, or metrics.

3: Provides useful background but limited evidence.

1: Provides little evidence for route decisions.

## 4. Recency or Foundational Value

5: Recent and directly relevant, or foundational and widely cited.

3: Useful but not central.

1: Outdated or peripheral.

## 5. Venue and Review Quality

5: Top journal/conference, IEEE/ACM Transactions, Nature/Science family, or recognized foundational venue.

3: Solid peer-reviewed venue, but not clearly top-tier.

1: Weak, unclear, predatory, or low-confidence venue.

## 6. Practical Grounding

5: Connects to deployed systems, standards, policy, measurement, or real operational constraints.

3: Has plausible practical assumptions but needs external validation.

1: Mostly academic concept with unclear deployment path.

## Decision

- `high relevance`: average score >= 4
- `medium relevance`: average score >= 2.5
- `low relevance`: average score < 2.5

Do not fabricate scores for unread papers. Use `metadata only` when needed.

Low-tier papers can be kept as candidates, but they should not dominate a route card unless corroborated by high-quality or practical sources.
