# 仓库边界

本仓库是 Level 0 研究情报助手。

## 可以提交

- `data/items.jsonl`
- `data/manual_items.jsonl`
- `outputs/weekly/*.md`
- `outputs/review_dashboard.md`
- `notes/items/*.md`
- `topics/<topic>/synthesis.md`
- `topics/<topic>/open_questions.md`
- `topics/<topic>/possible_directions.md`
- 轻量脚本、配置和 workflow

## 不应提交

- 大 PDF；
- 受版权限制的 full-text dumps；
- datasets、checkpoints、长实验日志；
- Level 1 实现代码；
- 未经人工复核的最终研究结论；
- 自动生成的 novelty claim 或建仓建议。

本地 PDF 可以放在：

```text
literature/inbox/papers/
```

该目录默认忽略 PDF 文件。
